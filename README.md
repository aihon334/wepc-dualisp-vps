## 先搞清楚：双ISP IPv4 VPS到底是个什么东西

咱们先把概念理顺。"双ISP"指的是同一个IPv4地址被两家互联网服务提供商同时登记为家庭宽带用户IP。注意关键词——"家庭宽带"，不是数据中心，不是机房托管。
